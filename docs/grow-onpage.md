Cheerio 1.2.0 (MIT) analyzes the initial public HTML in parallel with PageSpeed. No paid API or additional SerpKite credit is required. It reads up to three sampled pages; the HTML request uses bounded time/bytes and pinned public IPv4, no cookies or form submission. Dynamic JavaScript and blocked sites are not measured. The PDF selects five checks; the dashboard shows all checks. Backlinks, actual conversion rates, actual indexing and form functionality remain unmeasured. No raw HTML is stored; Gemini receives only structured facts. Robots and sitemap discovery are conservative/best-effort. Older reports do not have HTML observations until a new audit. No database migration required.
